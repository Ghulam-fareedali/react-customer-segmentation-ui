# React Customer Segmentation UI

A modern and responsive customer segmentation UI built with React and Tailwind CSS.

## 🚀 Live Demo
https://react-customer-segmentation-ui-n4w8.vercel.app

## 🛠️ Technologies Used
- React.js
- Vite
- Tailwind CSS
- CSS3
- Remix Icons

## 📦 Run Locally

```bash
git clone https://github.com/Ghulam-fareedali/react-customer-segmentation-ui.git
cd react-customer-segmentation-ui
npm install
npm run dev
```
